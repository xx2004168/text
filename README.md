# 基于微服务架构的商城系统

一款采用Spring Cloud Alibaba生态构建的分布式商城解决方案，实现用户登录、商品展示、订单交易、库存管理等全流程数字化，具备高可用、可扩展、易维护的微服务架构特性。

## 项目概述

- **核心目标**：解决传统单体电商系统扩展性差、维护成本高等问题，通过微服务拆分实现业务解耦，支持高并发交易和灵活迭代。
- **应用场景**：线上商城，Web购物支持。
- **架构优势**：服务独立部署与扩展、故障隔离不影响整体系统、支持多团队并行开发、适配业务快速迭代需求。

## 技术栈详情

### 核心框架

- 后端框架：Spring Boot 2.3.12.RELEASE、Spring Cloud Hoxton.SR12、Spring Cloud Alibaba 2.2.8.RELEASE
- 服务治理：Nacos 2.0.3（服务注册+配置中心）、OpneFeign（远程服务调用）、Sentinel 1.8.0（限流熔断）
- API网关：Spring Cloud Gateway（路由转发、统一鉴权）

### 数据存储

- 关系型数据库：MySQL 8.0（核心业务数据存储）
- 缓存中间件：Redis 7.0（热点数据缓存、分布式锁、购物车存储）
- ORM框架：MyBatis-Flex 1.10.3（数据访问层简化）
- 消息队列：RabbitMQ 3.9.11（异步通信、削峰填谷）

### 工程化与工具

- 构建工具：Maven 3.8+（依赖管理、项目构建）
- 版本控制：Git（代码管理）、GitHub（远程仓库）
- 容器化：Docker（服务容器化部署）
- 认证授权：JWT（分布式身份认证）

## 关键架构特性

- 服务解耦：基于业务能力划分微服务，模块间通过RESTful API和消息队列通信，降低依赖耦合度。
- 高可用设计：服务多实例部署、Sentinel限流熔断防止服务雪崩、Redis缓存减轻数据库压力。
- 可扩展性：支持按需扩展单个微服务，无需整体系统扩容。
